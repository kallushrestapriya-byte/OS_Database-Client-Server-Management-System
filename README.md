# Database Client-Server Management System

## Project Description

A Linux-based Database Client-Server Management System developed using C programming.

The system demonstrates client-server communication and basic student database management.

## Features

- Add student records
- View student records
- Update student records
- Delete student records
- TCP socket communication
- Linux system calls
- File handling

## Technologies Used

- C
- Linux / Ubuntu
- GCC
- TCP Socket Programming
- Git and GitHub
